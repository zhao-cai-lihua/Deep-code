    FIRST RUN · DESKTOP APP

    欢迎来到 Deep code。

    四步准备本地 Runtime、规范工作区与模型连接。这里是 Windows 桌面程序，可以打开原生文件夹选择器；GitHub 网页本身不能替你访问本地目录。

    1

    找到官方 Harness

    先自动检查桌面和 Deep code 的文档目录；也可以用 Windows 原生选择器手动指定。

    2

    没有 Harness？自动准备

    将从官方 GitHub 仓库克隆到 Documents\Deep code Runtime，安装依赖并构建。电脑需要已安装 Git、Node.js 和 pnpm；缺少时会明确告诉你是哪一项。

    3

    创建第一个工作区

    自动生成 README、Agent 协作约定、Git 忽略规则与本地项目元数据；不会覆盖同名文件夹。

    4

    确认模型连接

    点击后会明确启动 Engine，再只读检查模型目录和 API Key 是否已配置。Deep code 只能看到“已配置/未配置”，不会读取密钥内容。

    等待开始。每一步都会在这里明确显示进行中、成功或失败。
