# Deep code v0.8.0-beta.1

This local candidate is superseded by v0.8.0-beta.2 and must not be published or promoted. Its Plan selector incorrectly sent `/plan` through the ordinary `session.prompt` channel on the pinned API Proxy, which made the control text a model-visible user message.

## What changed

- Replaced the local four-stage Task Journey with a `GuidedWorkbenchSnapshot` projected from Harness facts. Harness remains the only authority for Session, Plan, Todos, model route, token usage, tools, permissions, and terminal state.
- Added strict validation for `session.history.projections` and live `session/projection` events. Only known, schema-valid, higher-sequence values enter the product projection; unknown or malformed payload bodies are discarded and only anonymous counts remain.
- Added explicit Direct and Plan controls backed by Harness `/plan off` and `/plan`. A mode change is accepted only after the corresponding structured Plan projection appears.
- Reworked the task surface into left navigation, centered conversation, and a sticky right inspector. The inspector folds on narrow layouts; tool and reasoning detail stays in Trace instead of fragmenting the answer.
- Added coalesced live patches with immediate Decision Gate and terminal delivery, 15-second durable reconciliation, paged history in 80-message batches, an 800-message UI cap, and task/Session/generation guards.
- Added exact Session token buckets and approximate context pressure only when Harness supplies those projections. Deep code still does not guess currency cost.
- Added optional privacy-safe native notifications for waiting, completed, failed, and interrupted transitions while the window is not in front.
- Removed the unreachable ecosystem installer path, the superseded Task Journey modules, false unconfirmed-change inference, unused Adapter projections, and stale CSS/runtime exports identified in the dead-code review.

## Bounded manual acceptance

These checks use at most one ordinary low-cost model task. The remaining checks are local UI observations.

1. Start a new Direct task and confirm the center remains a continuous readable conversation while tool activity stays in the right inspector or Trace.
2. Start a Plan task and confirm the inspector shows Harness Plan mode and its structured Todos. If Harness does not confirm the mode within three seconds, Deep code must stop and explain the failure rather than continue.
3. While a task is streaming, switch to another task and back. No draft, activity row, history page, open dialog, or inspector state may cross tasks.
4. Resize the window below the three-column breakpoint and confirm the inspector can be folded and reopened without changing task state.
5. Leave Deep code unfocused and let a test task finish or request a decision. At most one generic notification should appear; it must contain no task text or path. Disable notifications in Settings and confirm later transitions remain silent.
6. Load earlier messages in a long task and confirm the reading position is retained. Repeated loads must remain bounded and must not duplicate messages.

## Boundaries

- The supported Harness runtime remains pinned to `dsh-v0.1.1-rc.2` / `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`.
- This release does not add automatic model routing, plugin execution, automatic Memory injection, companion-card prompts, Goal orchestration, Git rollback, or estimated currency cost.
- v0.7.1-beta.2 remains historical and must not be promoted; its local Task Journey has been removed rather than made into a second execution state machine.
