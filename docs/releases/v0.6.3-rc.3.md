# Deep code v0.6.3-rc.3

这是 v0.6.3 安全与证据边界的第三个测试候选，尚不是稳定版。它继承 rc.2 的 Engine Trust Gate，并修复模型凭据与真实验证结果在界面上互相覆盖的两个问题。

## 本次修复

- “凭据已保存”只表示 Harness 报告对应凭据槽有值，不再被写成“尚未验证”。
- “运行时与设置”的模型连接区会同时显示该 Provider 最近一次可归属的真实验证结果、模型、时间及历史边界。
- 旧任务的认证失败会明确写成“这一轮请求当时失败”，不会暗示后来保存的凭据仍然失败。
- 如果没有更晚的通过记录，恢复指引才建议用户替换 API Key；已有更晚证据时不再要求无意义地重复输入同一个密钥。
- 密钥内容仍不会被读取、回显、写入日志或复制到验证回执。

## 诊断边界

本机只读检查确认当前 DeepSeek 与 GLM 凭据均由 Harness 报告为文件来源且可写；固定 Harness 源码会在每次请求时重新解析凭据，并已有无需重启即可轮换 Key 的上游测试。因此本次没有加入“重启 Engine”或“自动重写 Key”之类缺乏证据的规避方案。

验证回执是历史事实：它证明指定 Provider、模型和推理强度在记录时间对应的那一轮 Harness 请求通过或失败，不承诺凭据永久有效。
