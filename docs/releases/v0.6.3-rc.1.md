# Deep code v0.6.3-rc.1

这是安全与证据边界的测试候选，尚未经人工验收，不是稳定版。请先使用低价值测试 Key、非敏感工作区和已有备份完成验收。

## 本候选修复什么

- 托管 Engine 改用系统分配的回环端口，并同时核对官方固定版本、Git HEAD、`host.describe` 结构与工作目录；`3080` 上的外部 Engine 必须由用户逐实例确认。
- 托管 Engine 只继承运行所需和用户明确配置的代理环境变量，不继承未知 Key、Token、Secret、Password、Credential 或 `NODE_OPTIONS`。
- 自动安装固定到官方 `dsh-v0.1.1-rc.2` 与 Git SHA `b150a551b8d465e31e418e1b2eaf5e79bbb7d28e`，校验失败前不会运行仓库脚本。
- 生态发现保留，实际安装入口暂停并从 Renderer、Preload 与 Main IPC 中移除。
- Memory 对 ID、最终路径、目录状态、重复记录和秘密内容重新验证；状态迁移使用同盘原子移动，异常记录进入本地隔离区。
- 本地任务改用不可变的版本快照并保留三个有效版本；损坏时回退。Electron 第二实例只聚焦首个窗口，不成为第二个写入者。
- 引入 Harness Evidence Gate：接纳、开始、终态、实际模型、权限和文件改动只从同一 Session、同一轮的结构化事件或独立 Git 基线投影；缺少证据时明确显示未知。
- 运行中的删除变成“停止并删除”：先取消并等待同轮终态，十秒未确认就保留任务记录。
- 工作台异步刷新带任务、Session 和 generation 门禁，迟到的旧任务快照不能覆盖当前任务。

## 当前边界

- `host.describe` 是兼容性与能力检查，不是密码学身份认证；外部共享 Engine 始终需要明确确认。
- 当前只兼容已经人工验收的 Harness `0.1.1-rc.2`。`0.1.2-rc.1` 尚未进入自动兼容清单。
- Memory 仍是本地档案，不进入 Agent Prompt。
- 生态项目不能从本候选版本直接安装。
- Harness 当前没有提供统一、可核对的费用账单时，Deep code 不估算 token 或人民币费用。

自动测试与本地打包已经通过；打包应用启动冒烟和砚星列出的人工项目仍待完成。只有这些项目均通过后，才会发布 v0.6.3 stable。
