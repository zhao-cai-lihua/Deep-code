# Deep code v0.6.2

这是经过 rc.3 人工验收的正式收束版，面向不熟悉代码的 Windows 用户。v0.6.1 的云端发布被一项 Windows 换行兼容性测试拦住，没有发布安装文件；本版修复该测试，并增加合并前自动检查，产品功能保持不变。

## 下载与使用

- **Deep.code.Setup.0.6.2.exe**：安装版，推荐普通用户使用。
- **Deep.code.0.6.2.exe**：便携版，下载后运行。

两者功能相同，只选一种。关闭旧版后再启动新版，不必删除工作区、任务或 Engine 配置。本版没有商业代码签名，Windows 可能提示发布者未知；请核对来源与发布文件后自行决定是否运行。

Deep code 仍需要本机 DeepSeek Harness Engine，首次向导可检测或准备它。模型 API 由所选服务提供方计费。

## 本版改进

- 模型目录、已保存凭据、真实连接验证和实际采用路线分开展示。保存 Key 不等于验证成功；验证任务留下可归属的回执。
- 修复旧 Session 默认模型阻塞明确选择、Provider 选择跳转、模型与推理强度选择器切屏后失去交互等问题。
- 添加模型服务前，二次确认具体厂商；改动厂商、Key 或超时都会重置确认。误加服务可以移除。
- 任务各自绑定工作区，旧任务可返回自己的项目，侧栏可打开实际文件夹。
- 用户问题保持可输入、可选择；输入活动刷新五分钟等待期限。运行中的任务可停止。
- 对话、回执与轨迹分区。回执说明确认改动、验证结果、高影响操作与恢复限制；Git 基线不冒充恢复点。
- 认证、额度、网络等失败给出对应的下一步。原始运行上下文需要主动展开。
- 本地记忆收件箱可确认、拒绝、删除、按项目检索及预览；尚不自动加入模型提示词。

## 范围与验证

Deep code 是社区独立桌面客户端，仍处于早期阶段。Harness 负责会话、权限、工具和执行状态。当前没有自动跨厂商路由、自定义兼容端点/OAuth 的完整配置界面、自动记忆注入、费用账单或通用自动回滚。

rc.3 人工验收通过；本地 197 项回归通过。正式安装文件由对应标签的 Windows 工作流测试通过后构建，不包含本地用户数据。当前测试同时覆盖 LF 与 CRLF，避免换行格式造成假失败。
