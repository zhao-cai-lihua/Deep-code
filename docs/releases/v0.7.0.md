# Deep code v0.7.0

这是 Evidence Gate 的首个稳定版。它把 DeepSeek Harness 已经证明的运行事实整理成普通人能快速读懂、需要时又能逐层追溯的对话、回执与轨迹界面；Deep Code 仍不建立第二套 Agent 或执行状态机。

稳定版与砚星已经验收通过的 `v0.7.0-rc.1` 使用同一份运行与测试源码。候选版 tag 之后没有 `src/` 或 `test/` 改动；正式版准备只更新版本号、发布说明与交接记录。

## 这一版带来了什么

- “轨迹”先显示本轮状态、工具数量、确认的文件改动和失败数量；工具输出、权限、Git 基线、运行上下文与原始证据按需展开。
- “回执”的“查看证据”会切换到对应轨迹并展开目标证据；技术证据不会再藏在仍关闭的外层中。
- Trace 的状态与计数只来自 Run Projection，显示层不再根据零散 Outcome、工具或 Engine 字段重建另一套结论。
- 尚未得到 Harness 终态的取消请求保持未知/等待确认；同一 Turn 的匹配终态到达后才替换旧恢复提示。
- 每个任务独立保存轨迹、回执和证据的展开状态，切换任务不会串联功能区状态。
- 工作台正文不再重复顶部已有的任务标题，同时保留项目路径与显式切换项目入口。

## 不变的安全边界

- DeepSeek Harness 是 Session、Provider、模型、权限、工具与终态的唯一执行真相。
- 本版不改变 API Key、Provider Profile、模型路由、推理强度、Engine 信任、工作区文件操作或 Memory Prompt 边界。
- 生态发现仍为只读，实际插件安装仍停用。
- 只支持已经固定并验证的 Harness `dsh-v0.1.1-rc.2`，不自动追随上游 Developer Preview。
- Harness 没有提供 token 或费用事实时，Deep Code 明确显示未知，不推测或估算金额。

## 验证与验收

- 投影、Evidence View、任务视图状态与 Renderer 契约聚焦测试：59 项通过。
- 全量 `npm test`：275 项通过。
- 生产依赖审计：没有已知漏洞。
- 砚星于 2026-09-11 在候选版中完成四项零 token 人工验收：紧凑轨迹层级、回执到证据的导航、任务间展开状态隔离，以及自然出现的未确认停止文案观察，全部通过。
- Windows 安装版、便携版与 `SHA256SUMS.txt` 由 GitHub Actions 从正式 tag 重新测试并构建。

除非后续实现发生变化，不需要重复候选版的四项人工测试。
