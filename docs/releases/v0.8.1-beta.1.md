# Deep code v0.8.1-beta.1

This is the manually accepted prerelease for the Harness Capability Gate milestone. It is not the stable release; v0.7.0 remains the recommended stable version while the new compatibility boundary is exercised on real machines.

## What changed

- Deep code now derives one explicit capability snapshot from the verified managed Harness runtime instead of assuming that every endpoint or control exists.
- Session creation, prompt admission, model selection, Plan control, and host-care actions are gated independently. A missing or unverified capability stays unavailable and receives a human-readable reason.
- Prompt admission must return the expected Session binding before Deep code treats the request as accepted. A missing or mismatched Session identity fails closed.
- Runtime restarts and disconnects clear the previous capability snapshot, preventing stale support claims from leaking into a new Engine process.
- Runtime settings now show the verified Engine profile, capability status, and unavailable reasons without turning `host.describe` into a claim of cryptographic identity.
- Repeated host-care recovery requests are deduplicated so one unresolved condition does not create overlapping repair attempts.

## What this prerelease does not claim

- It does not add a second Agent Loop or a Deep code-owned execution state machine. DeepSeek Harness remains the authority for Session, model, permission, tool, Plan, and terminal facts.
- It does not make Plan remotely selectable on the pinned `dsh-v0.1.1-rc.2` runtime. That runtime does not expose the required command plane through the verified remote surface, so the control remains unavailable.
- It does not automatically support Harness `0.1.5-rc.2` or any later tag. Each runtime needs its own pinned compatibility profile, protocol fixtures, isolated startup check, packaging check, and bounded manual acceptance.
- It does not install ecosystem projects, inject Memory or companion cards into prompts, infer Provider identity from API keys, or estimate money when Harness supplies no attributable price fact.
