# Deep code v0.6.1

面向不熟悉代码的 Windows 用户：让模型连接、任务状态、工作区和失败后的下一步更容易理解。本版由经过人工验收的 rc.3 收束发布。

## 下载与使用

- **Deep.code.Setup.0.6.1.exe**：安装版，推荐普通用户使用。
- **Deep.code.0.6.1.exe**：便携版，下载后运行。

两者功能相同，选择其中一种即可。关闭旧版 Deep code 后再启动新版；不必删除项目、任务或 Engine 配置。Deep code 仍需要本机 DeepSeek Harness Engine，首次向导可检测或准备它。模型 API 服务由用户选择的提供方计费。

## 本版改进

- 模型服务分开展示 Provider、模型目录、已保存凭据、真实连接验证与当前任务采用的模型。保存 Key 不会被当作连接成功；验证任务留下与实际请求路线对应的回执。
- 修复明确选择模型仍被旧 Session 默认路线阻塞、Provider 选择跳转，以及模型/推理强度选择器切屏后失去交互的问题。
- 添加模型服务时明确显示厂商，并要求二次确认。修改厂商或 Key、等待超时都会清除旧确认。误加的 Provider 可移除。
- 任务保留自己的工作区，旧任务可直接返回对应项目。侧栏显示文件夹位置并可打开。
- 对话、回执与轨迹分区；问题等待与用户输入保持稳定，输入活动重置五分钟等待期限，运行任务可以停止。
- 回执说明确认的改动、验证结果、高影响操作与恢复限制。Git 基线仅记录改动归属，不冒充可回滚的恢复点。
- 认证、额度、网络等失败给出对应的下一步；运行上下文默认使用技术摘要，原始内容可展开查看。
- 本地记忆收件箱支持确认、拒绝、删除、按项目检索与选中内容预览；当前预览尚未接入任务提示词。

## 已知范围

这是社区独立桌面客户端，产品仍在早期阶段。Harness 是会话、权限、工具和执行结果的来源。当前尚无自动跨厂商路由、自定义兼容端点/OAuth 的完整配置界面、自动记忆注入、费用账单或通用自动回滚。模型目录和 API Key 存在均不保证调用成功。
