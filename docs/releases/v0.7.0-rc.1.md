# Deep code v0.7.0-rc.1

这是 Evidence Gate 的首个 v0.7 候选版，尚不是稳定版。它不增加第二套 Agent 或执行状态机，而是把 Harness 已经证明的事实做成普通人能看懂、能追溯、又不会默认铺满屏幕的工作界面。

## 这一版有什么变化

- 对话、模型服务和任务证据分别拥有行为测试覆盖的显示边界，庞大的工作台脚本不再直接承担所有展示细节。
- “轨迹”默认先显示一张结论卡：本轮状态、工具数量、确认的文件改动和失败数量。工具输出全部默认收起，权限、Git 基线、运行上下文与原始证据再深一层。
- “回执”中的“查看证据”会真正打开对应位置；技术证据链接会同时展开外层和内层，不再滚动到一块仍然隐藏的内容。
- Trace 的状态和计数只来自 Run Projection。View 不再根据 Outcome、工具或 Engine 字段重建另一套结论。
- 取消请求尚未得到 Harness 终态时仍显示“未知/等待确认”，不会被叫成失败；匹配终态稍后到达时会覆盖旧的恢复标记。
- 每个任务保留自己的轨迹/回执展开状态，切换任务不会把另一个任务的面板一并展开。
- 工作台正文不再重复显示与顶部相同的任务标题，项目路径和显式切换项目动作仍保留。

## 不变的安全边界

- DeepSeek Harness 继续是 Session、模型、权限、工具和终态的唯一执行真相。
- 本版不改变 API Key、Provider Profile、模型路由、推理强度、Engine 信任、工作区文件操作或 Memory Prompt 边界。
- 生态发现仍然只读，实际插件安装仍停用。
- 仍只支持已经验证并固定的 Harness `dsh-v0.1.1-rc.2`；不会自动追随上游 Developer Preview。
- Harness 没有提供 token 或费用事实时，Deep code 仍明确显示未知，不估算金额。

## 自动验证

- 投影、Evidence View、任务视图状态和 Renderer 契约聚焦测试：59 项通过。
- 全量 `npm test`：275 项通过。
- 生产依赖审计：没有已知漏洞。
- Windows 安装版与便携版由同一固定提交在 GitHub Actions 中重新测试、构建并生成 SHA-256 校验文件。

## 砚星的低成本验收

不需要重新输入 API Key，也不需要专门发起一次付费模型请求。可以直接查看已有的已完成任务：

1. 打开“轨迹”，确认先看到简短状态卡；工具行默认收起，权限、Git 基线与技术证据也默认收起。
2. 打开“回执”，点击任一“查看证据”。确认它切到轨迹并显示对应证据；技术证据不再藏在仍关闭的外层里。
3. 在一个任务中展开工具或技术证据，再切到另一个任务。确认另一个任务不会继承这些展开状态。
4. 若日常使用中自然遇到“停止仍待 Harness 确认”，只观察文案是否保持黄色/未知；不要为了测试专门制造五分钟等待。

通过这四项后，v0.7.0 才进入稳定版准备。
