# Deep code v0.6.1-beta.2 测试版

这是面向 Decision Gate 可靠性和任务可恢复性的增量测试版，不是正式发布。

## 本版变化

- 修复用户提交决定时，五分钟空闲计时可能先取消任务、导致 Engine 返回未确认的竞态。
- 用户持续输入或修改选项时重新开始五分钟空闲计时；活动检测只在本机运行，不调用模型。
- Engine 已不再等待该决定时，显示明确的原因、安全说明和下一步恢复动作。
- Recovery 直接显示在当前对话中，不再只藏在技术状态区域。
- 输入区增加“停止”入口，复用 Harness 的任务取消路径。

## 已知限制

- 中间思考和工具过程尚未合并成单个折叠过程行。
- 当前运行面板仍位于左侧；迁移到右侧可折叠检查器将在后续完成。
- Harness 当前没有经 Deep Code Adapter 提供可靠的 token usage，所以本版仍明确显示用量未知，不估算金额。
- 测试版 EXE 未签名，Windows 可能显示 SmartScreen 提示。
