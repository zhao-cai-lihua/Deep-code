# Deep code v0.6.3-rc.6

这是 v0.6.3 安全候选的窄范围人工验收修正版，尚不是稳定版。rc.5 的 Engine、Provider、模型路由和 Evidence Gate 保持不变；本版只修复任务输入草稿串线，以及停止状态中相互矛盾的说明。

## 本次修复

- 每个任务拥有独立的本机内存文字草稿，“新任务”也有自己的独立草稿。A 中未发送的文字不会出现在 B；切回 A 时仍能找回 A 的内容。
- 只有发送成功才清除当前来源草稿。切换失败、异步结果迟到或切到别的任务不会误清、误归属文字。
- 五分钟等待超时后，没有 Harness 终态时显示黄色“停止仍待 Harness 确认”，不再把停止请求当成已停止。
- 若 Harness 后来给出匹配的中止终态，界面改为红色“这一轮已停止”，并用终态事实替换旧的“尚未确认”文案。
- 恢复卡中的标签从容易误解的“已经确认”改为“状态边界”。

## 边界

- 未发送草稿只保存在当前 App 进程内，不写入任务文件，不交给 Harness，退出 App 后不承诺恢复。
- 本版不改变 API Key、Provider Profile、模型、推理强度、Session、权限或工作区文件。
- 不需要重新验证模型连接，也不需要为测试重新输入 API Key。
