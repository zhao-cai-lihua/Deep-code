# Deep code v0.6.1-beta.3 测试版

这是修正 Recovery 可见位置的增量测试版。

## 本版变化

- 五分钟等待用户超时后，“原因 / 已确认 / 下一步”固定出现在当前对话的最新边缘、发送框之前。
- 左侧本轮状态仍保留摘要，但不再成为用户寻找恢复动作的主要位置。
- 增加界面顺序回归测试，防止 Recovery 再次被放回整段对话之前。

## 已知限制

- 当前运行、Outcome 和证据仍在左侧；迁移到右侧可折叠检查器将在后续完成。
- 中间过程折叠与自适应模型路由仍处于设计/适配阶段，本版没有启用隐藏自动路由。
- 测试版 EXE 未配置发行者证书，Windows 可能显示 SmartScreen 提示。
