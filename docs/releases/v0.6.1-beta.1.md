# Deep code v0.6.1-beta.1 测试说明

这是供本机审查的 Beta 便携版，不是正式发布。

文件名带有 `Test`，但应用身份仍是 `Deep code`，因此会复用现有的本机 Engine 路径、工作区设置与任务数据，不需要重新跑首次向导。

重点验证：

- 等待用户回答的卡片位于对话底部，选择和输入不会被后台刷新清空；
- 五分钟没有回答时，本轮停止，并明确说明原因、影响和下一步；
- Outcome / Recovery 不再只给出“失败”，而会给出确认事实和可执行动作；
- 生态项目可先检查固定 commit 与 `dsh.bundle.patch`，再次确认后通过官方 CLI 安装到官方 `web` profile；
- Deep Code 管理的 Engine 使用同一 `web` profile，停止已有 Harness 并从 Deep Code 重启后加载已安装 Bundle。

已知限制：

- 插件管理暂时没有已安装列表、卸载按钮和 profile 自动回滚；只应测试你信任且看过源码的项目。
- GitHub 源依赖若要求 `prepare`，pnpm 可能要求额外的构建许可；测试版会原样报告官方 CLI 的失败原因，不会绕过它。
- Engine 手动定位与安全工作区创建的已报告问题按本轮约定延期。
