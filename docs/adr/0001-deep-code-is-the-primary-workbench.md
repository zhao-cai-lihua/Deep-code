# Deep code is the primary workbench above a hidden DSH Engine

Deep code will not open or embed the official Harness UI as its normal task flow. The official DeepSeek Harness remains the sole execution truth for sessions, tools, approvals, permissions, models, and plugins, while Deep code directly consumes its supported local protocols and owns the only beginner-facing Workbench, because exposing two products makes state, navigation, and responsibility incomprehensible to the intended user.

## Consequences

Deep code must implement and version a thin DSH Adapter, preserve raw evidence behind every human-facing translation, and fail visibly when an upstream capability such as live approval has not yet been adapted. It must not invent a parallel Agent Loop or permission system to fill those gaps.
