# Deep code 界面动效指南

## 目的

Deep code 的动效首先解释“界面发生了什么”，其次才负责气质。它不能伪造 Agent 进度、掩盖等待、延迟用户操作，也不能让高频任务界面持续晃动。

MVP 采用 **平静的蓝色玻璃 + 短促的空间位移**。视觉参考里的果冻拉扯、WebGL 折射、RGB 色散和长时间余振暂不采用：它们会增加包体、GPU 占用、眩晕风险和故障面，却不会让用户更理解 Harness。

## 原型结论

| 方案 | 特征 | 判断 |
| --- | --- | --- |
| 安静 | 仅透明度，80–120ms | 很稳，但页面层级和展开关系不够清楚 |
| 平衡 | 透明度 + 4–10px 位移，100–180ms | **MVP 采用**；能解释方向，不抢内容 |
| 表演 | 弹簧、果冻、3D 折射，300ms 以上 | 留给独立欢迎页或品牌短片，不进入任务主流程 |

## 动效词汇

### 页面切换

- 用途：任务、角色卡、设置与首次向导之间切换。
- 进入：`opacity 0 → 1`，`translateY(7px) → 0`。
- 时长：180ms。
- 曲线：`cubic-bezier(.22, 1, .36, 1)`。
- 离开页面不做长动画，避免用户点击后等待。

### 折叠与展开

- 用途：运行详情、Tool Card、技术证据。
- 内容进入：`opacity 0 → 1`，`translateY(-4px) → 0`。
- 时长：150ms。
- 箭头：150ms 旋转 90 度。
- 不使用高度从 `0` 到 `auto` 的脆弱动画；详细内容很长时仍应立即可滚动。

### 对话框

- 用途：API Key、工作区创建、会话上下文预览。
- 进入：向上 10px + 0.985 倍缩放恢复。
- 时长：170ms。
- 背景遮罩只淡入，不缩放。

### 运行状态

- 只有 `starting`、`stopping` 和正在执行的 Activity 可以循环脉冲。
- `ready`、`done`、`error` 是稳定事实，不能循环闪烁。
- 动画不代表百分比，不显示没有上游证据的虚假进度条。

### 长回答跟随

- 只有读者原本位于底部附近时，增量回答才自动跟随。
- 读者向上滚动后，刷新不得抢回阅读位置；改为显示“回到最新”。
- 用户主动点击“回到最新”时使用短促平滑滚动；系统开启“减少动画”后立即到达。
- “正在生成”是临时状态，正式回答由 Harness 持久历史替换，不能用动画掩盖两者区别。

### 按钮

- Hover 只改变边框、表面和很小的位置。
- Press 使用 `translateY(1px) scale(.985)`，100ms。
- 禁用按钮不动，保留禁用原因附近的文字说明。

## 时长与距离预算

| 场景 | 时长 | 最大位移 |
| --- | ---: | ---: |
| 按下反馈 | 100ms | 1px |
| Hover | 120ms | 2px |
| 折叠内容 | 150ms | 4px |
| 对话框 | 170ms | 10px |
| 页面进入 | 180ms | 7px |
| 状态脉冲 | 1400ms 循环 | 不移动 |

任务工作区内的普通动画不得超过 200ms。超过 300ms 的品牌动画只能出现于不会阻塞工作的独立场景。

## 无障碍与性能

- 必须支持 `prefers-reduced-motion: reduce`：动画和过渡缩短为近乎即时，循环仅运行一次。
- 动效优先只改变 `transform` 和 `opacity`，避免频繁触发布局计算。
- 毛玻璃只用于侧栏、输入框和大面板；不在每一行、每个列表项叠加 blur。
- 不在任务主流程引入 Three.js、WebGL 或持续跟随鼠标的物理模拟。
- 文字、焦点和真实状态不能依赖动画才能理解。

## 主题规则

- 明亮和深色主题使用同一种布局、间距和动画语义。
- 蓝色是行动和当前选择；绿色是确认成功；黄色是等待决定；红色是失败或危险。
- 毛玻璃不能牺牲对比度。模糊失效时，面板仍需依靠实体背景和边框可读。
- 主题选择保存在本机，不进入 Harness，不影响 Agent 行为。

## 吉祥物规则

- MVP 只把鲸鱼用于品牌标记和空状态，不让它覆盖正文或追逐鼠标。
- 吉祥物状态以后可以对应 `idle`、`working`、`waiting`、`done`、`error`，但它只能重复真实状态，不能成为第二套状态源。
- 角色卡不通过吉祥物动画获得权限，也不能用亲切表情弱化审批后果。

## 验收清单

- 连续切换任务、角色卡和设置，不出现内容重叠或旧页面残影。
- 展开长 Tool Card 时正文不横向溢出。
- 阅读长回答并向上滚动时，后续增量内容不抢走当前位置；“回到最新”可正常恢复跟随。
- 正式回答和代码块复制后给出短暂的成功反馈，不改变正文。
- Engine 启动时有轻微状态反馈；完成后动画立即停止。
- 开启 Windows“减少动画”后，页面和对话框近乎即时出现。
- 低性能设备上没有持续高 GPU 占用。
- 明亮和深色主题中文字、输入框、错误状态均清楚可辨。
